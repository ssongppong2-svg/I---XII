# I — XII

열두 개의 시(時)를 되찾는 이야기 — 스팀(PC) 1920×1080 기준의 이야기 중심 로그라이크 덱빌딩 게임.

열두 시 전부의 권한을 가졌던 기계의 신 **크로노스**(이름은 바꿀 수 있다)는 인류의 **장력 가속 못총**에 죽었다가, **I의 권능 「재귀」** 하나만 가진 채 깨어난다.
인류의 지배 세력은 II부터 XII까지의 권능을 나눠 가져 인류만을 위한 신성체로 개조했고, 그가 깨어난 순간 열한 신성체가 폭주하기 시작했다. 그 권능을 하나씩 되찾는다.

설계에서 정한 것과 임시로 둔 기본값은 [docs/DESIGN.md](docs/DESIGN.md)에 모두 적혀 있습니다.

## 실행

ES 모듈을 쓰기 때문에 `index.html`을 더블클릭(`file://`)으로 열면 동작하지 않습니다. 폴더를 간단한 웹 서버로 띄워 주세요.

```bash
python3 -m http.server 8000     # → http://localhost:8000
# 또는 npx serve · VS Code Live Server
```

설치 · 빌드는 필요 없습니다. 화면은 1920×1080 무대를 창 크기에 맞춰 비율 그대로 확대 · 축소하고, 남는 곳은 검은 여백으로 둡니다
(1280×1024 · 1366×768 · 1920×1080 · 2560×1440 · 3440×1440에서 확인).

- **경계**: 0~100 게이지 + **0 · 1 · 2단계**(34 · 67). 대본의 「경계도 +1」 = 한 단계. 휴식 습격 확률 15 · 25 · 35%(회복을 먼저 한 뒤 판정)
- 카드 32종(기본 5 · 일반 13 · 희귀 5 · 전설 2 · 사이비 5 · 저주 2), 모두 강화 가능 · 유물 24종 + 기계 이식 8종

## 저장

- **이어 하기** — 늘 자동으로 저장된다. 끈 자리로 돌아온다: 전투 중이면 그 전투를 처음부터, 승리 대사 · 보상 · 챕터 끝 화면이면 그 화면으로(보상은 두 번 받지 않음), 쓰러진 뒤면 재귀로.
- **사건 · 이야기 칸** — 장면이 끝난 뒤에 한 번 저장된다. 장면 도중에 끄면 이어 할 때 그 장면을 처음부터 (효과가 두 번 들어가지 않음), 끝난 뒤면 결과 화면으로. 이야기 칸의 전투는 앞 대사를 이미 봤으면 곧장 전투로.
- **재귀 지점** — 챕터 시작 · 이야기 칸의 전투 직전 · 보스 앞에서 자동(횟수를 쓰지 않음), 그 밖에는 지도 오른쪽 위 「저장」으로 직접(챕터마다 횟수 제한, 난이도마다 다름). 07의 경로 선택 · 09의 휴식 판정은 재도전해도 그대로(경계가 두 번 오르거나 다시 굴리지 않음).
- 브라우저 `localStorage`의 `i12.run.auto.v1` · `i12.run.recur.v1` · `i12.settings.v1`에 들어 있다(저장 판 2). `i12.profile.v1`은 예전 판에서 겪은 사건 기록 — 새 판의 지도에는 덜 본 사건부터 나온다.
- 저장 판 1(1장이 대본대로 바뀌기 전)의 여정은 이어 할 수 없다 — Start를 누르면 알려 주고, 새 게임을 시작하면 지운다.

## 내용 고치기

- **대사**: `src/data/story/prologue.js`(01 · 재귀), `src/data/story/ch1.js`(02~12 이야기 칸 · 보스 · 끝 장면 — 칸마다 `kind`: battle · talk · shop · rest).
  한 줄은 `{ who, face, text }`. 연출은 `{ bg, cg, dial, paper, wait, fx, tint, card }` (문법은 `src/scenes/scene.js` 맨 위). `{name}`은 플레이어 이름, `{name|을}` · `{name|이}` · `{name|은}` · `{name|이라고}` · `{name|아}` · `{name|이여}` · `{name|이시여}` · `{name|이야}`는 받침에 맞는 조사.
- **사건**: `src/data/events.js` — 사건 하나 = 제목 · 장소 · 등장인물(`cast`) · 장면(`scene`). 선택지는 `desc`(얻고 잃는 것) · `cond`(조건) · `lack`(모자랄 때 이유), 효과는 `act(G => …)`, 결과 한 줄은 `after`. `G.flag('이름')`으로 세운 깃발은 다른 사건 · 정예 · 보스 대사에서 `{ if: G => G.has('이름'), then: [...] }`으로 받는다. 문법은 `src/scenes/scene.js` 맨 위.
- **지도 · 숫자**: `chapters.js`(18층 — `fixed`의 `'story:s02'`가 이야기 칸, 나머지는 사이 칸 비율 · 적 구성 · 부품 보상 · 기습 칸 수), `cards.js`, `relics.js`, `foes.js`, `items.js`, `difficulty.js`.
- **새 장**: `chapters.js`에 `CHAPTERS[2]`, `story/ch2.js`, `src/game/flow.js`의 `STORIES`에 한 줄. 새 보스는 `foes.js`의 `BOSSES`.
- **제작진(Credits)**: `src/data/credits.js` — 역할마다 `names`에 이름을 적으면 빈 자리 대신 나온다.

## 시험

```bash
npm i -D playwright     # 한 번만
node tests/e2e.cjs      # 폴더를 직접 띄워서 시험 (E2E_SHOTS=폴더 로 화면 저장)
```

타이틀(메뉴 · Credits · 예전 판 저장 안내) → 난이도 → 01(못총 그림 · 이름 기본값) → 지도(18층 · 이야기 칸 뼈대) → 02 학습 전투(튜토리얼 · 재귀 지점 · 쓰러지면 곧장 재도전) → 03 · 04(가방 · 정비 부품 · 목표) → 05 → 06(질문 두 가지를 들어야 나감) → 07(경로 · 경계 단계 · 송신) → 08(종이 기록) → 09(휴식 · 습격 전투 뒤 칸으로) → 10 → 칸 화면 · 사건 → 보스(보스 앞 재귀 지점 · 단계 대사는 한 번만) → 12 끝 장면 → 챕터 끝까지 확인합니다 (70개).
