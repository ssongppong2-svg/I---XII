# I — XII

열두 개의 시(時)를 되찾는 이야기 — 스팀(PC) 1920×1080 기준의 이야기 중심 로그라이크 덱빌딩 게임.

열두 시 전부의 권한을 가졌던 기계의 신은 인류의 **장력 가속 못총**에 죽었다가, **1시의 힘 「재귀」** 하나만 가진 채 깨어난다.
나머지 열한 개의 시는 괴물이 되어 인류만을 위한 신으로 개조되었고, 1시가 깨어나자 폭주하기 시작했다. 그 권능을 하나씩 되찾는다.

설계에서 정한 것과 임시로 둔 기본값은 [docs/DESIGN.md](docs/DESIGN.md)에 모두 적혀 있습니다.

## 실행

ES 모듈을 쓰기 때문에 `index.html`을 더블클릭(`file://`)으로 열면 동작하지 않습니다. 폴더를 간단한 웹 서버로 띄워 주세요.

```bash
python3 -m http.server 8000     # → http://localhost:8000
# 또는 npx serve · VS Code Live Server
```

설치 · 빌드는 필요 없습니다. 화면은 1920×1080 무대를 창 크기에 맞춰 비율 그대로 확대 · 축소하고, 남는 곳은 검은 여백으로 둡니다
(1280×1024 · 1366×768 · 1920×1080 · 2560×1440 · 3440×1440에서 확인).

## 지금 들어 있는 것 — 1장 「재귀」

| 흐름 | 내용 |
|---|---|
| 타이틀 | 폐허 도시 그림 위 **Start · Settings · Credits · Exit** (나무판). Start는 저장이 있으면 Continue(이름 · 장 · 난이도 · 플레이 시간) · New Game |
| 난이도 | 시계 모양 I~XII — 처음부터 전부 고를 수 있고, 숫자(적 체력)와 규칙이 쌓인다 |
| 프롤로그 | 긴 각성 장면. "…인류는 그 신을 ???이라고 불렀다" → **당신의 이름은?** (이후 대사에 이름 · 조사가 맞춰 들어감) |
| 톱니 지도 | 챕터 전체가 하나의 톱니 장치. 칸을 끝내면 장치가 돌고, 놋쇠 축으로 이어진 톱니 중 하나를 고른다(고를 수 있는 축에 빛이 흐름). 칸 이름은 나무판. 16종 칸 · 경계도 · 직접 저장 |
| 전투 | **6×6 판** — 보스전은 맨 위 보스 줄 + 6×6. 4코스트 루프 · 적은 2코스트마다 · 2번째 행동 뒤 기습 폭격 |
| 사건 | **대사 장면** (한 길에 10~20줄). 고르는 것에 따라 얻고 잃는 것과 뒷이야기가 달라지고, 몇몇 선택은 다른 사건 · 정예 · 보스 대사까지 바꾼다. 한 지도에 같은 사건은 없고, 재귀로 되감긴 뒤 다시 만나면 기시감 |
| 튜토리얼 | 1장 첫 전투 두 번에 단계별 안내(건너뛰기 · 설정에서 다시 켜기) |
| 정예 · 보스 | 전투 앞뒤와 전투 중에 이야기. 보스는 **대형 감시기계** |
| 재귀 | 쓰러지면 마지막 저장으로 — 덱 · 유물 · HP · 지도 모두 그때로 |
| 챕터 끝 | 기록(플레이 시간 · 전투 · 처치 · 재귀) → 2장은 「준비 중」 (저장된 여정은 2장이 추가되면 그대로 이어짐) |

- 카드 32종(기본 5 · 일반 13 · 희귀 5 · 전설 2 · 사이비 5 · 저주 2), 모두 강화 가능
- 유물 24종(일반 10 · 희귀 8 · 보스 3 · 암시장 3) + 기계 이식 8종 — 얻으면 전부 켜짐
- 1장 사건 24종(대사 457줄) · 천막의 세계 소식 6줄 · 프롤로그 43줄 · 1장 정예 · 보스 대사 74줄 (**모두 초안**)
- 1장 적은 기계(감시 눈 · 태엽 사냥개 · 방벽 기계 · 폭뢰 딱정벌레, 정예 수문장 · 사냥개 우두머리) — **그림이 오기 전까지 임시 그림**. 시계 사수 · 방패 기사 · 폭탄병(무장한 인간)은 3장부터 나옵니다.
- 화면: 전투 · 휴식(2장) · 상점 · 골목 · 사건 · 타이틀 배경 그림, 대사창은 화면 끝까지, 모든 글은 타자 치듯(대사는 딸깍 소리), 카드는 양피지, 이름표 · 배너 · 메뉴는 나무판

## 조작

| 곳 | 키 |
|---|---|
| 타이틀 | `↑` `↓`로 고르고 `Enter` · 규칙 `H` · 소리 `M` |
| 지도 | 빛나는 톱니 클릭 (또는 `←` `→`로 고르고 `Enter`) · 덱 `D` · 유물 `R` · 규칙 `H` · 소리 `M` · 메뉴 `Esc` |
| 전투 | 이동 `W` `A` `S` `D` · 방향키 · 옆 칸 클릭 / 카드 `1`–`6` 또는 클릭(방향이 여럿이면 칸을 눌러 조준) / 뽑기 `Q` / 취소 `Esc` |
| 대사 | 넘기기 `Space` · `Enter` · 클릭 (타자 중이면 한 번에 다 보이기) / 선택지 `1`–`4` (흐린 선택지는 조건이 모자람) / 기록 `L` (고르는 중에도) / 자동 `A` / 건너뛰기 버튼 (선택지 · 이름 입력 앞에서 멈춤) |

## 저장

- **이어 하기** — 늘 자동으로 저장된다. 끈 자리로 돌아온다: 전투 중이면 그 전투를 처음부터, 승리 대사 · 보상 · 챕터 끝 화면이면 그 화면으로(보상은 두 번 받지 않음), 쓰러진 뒤면 재귀로.
- **사건** — 장면이 끝난 뒤에 한 번 저장된다. 장면 도중에 끄면 이어 할 때 그 장면을 처음부터 (효과가 두 번 들어가지 않음), 끝난 뒤면 결과 화면으로.
- **재귀 지점** — 챕터를 시작할 때 자동으로 한 번, 그 뒤로는 지도 오른쪽 위 「저장」으로 직접(챕터마다 횟수 제한, 난이도마다 다름).
- 브라우저 `localStorage`의 `i12.run.auto.v1` · `i12.run.recur.v1` · `i12.settings.v1`에 들어 있다. `i12.profile.v1`은 예전 판에서 겪은 사건 기록 — 새 판의 지도에는 덜 본 사건부터 나온다.

## 내용 고치기

- **대사**: `src/data/story/prologue.js`(프롤로그 · 재귀), `src/data/story/ch1.js`(1장 정예 · 보스 · 전투 중 장면).
  한 줄은 `{ who, face, text }`. `{name}`은 플레이어 이름, `{name|을}` · `{name|이}` · `{name|은}` · `{name|이라고}` · `{name|아}` · `{name|이여}` · `{name|이시여}` · `{name|이야}`는 받침에 맞는 조사.
- **사건**: `src/data/events.js` — 사건 하나 = 제목 · 장소 · 등장인물(`cast`) · 장면(`scene`). 선택지는 `desc`(얻고 잃는 것) · `cond`(조건) · `lack`(모자랄 때 이유), 효과는 `act(G => …)`, 결과 한 줄은 `after`. `G.flag('이름')`으로 세운 깃발은 다른 사건 · 정예 · 보스 대사에서 `{ if: G => G.has('이름'), then: [...] }`으로 받는다. 문법은 `src/scenes/scene.js` 맨 위.
- **숫자**: `chapters.js`(층 수 · 칸 비율(사건 칸 12 · 한 지도에 최소 4) · 적 구성 · 부품 보상 · 기습 칸 수), `cards.js`, `relics.js`, `foes.js`, `difficulty.js`.
- **새 장**: `chapters.js`에 `CHAPTERS[2]`, `story/ch2.js`, `src/game/flow.js`의 `STORIES`에 한 줄. 새 보스는 `foes.js`의 `BOSSES`.
- **제작진(Credits)**: `src/data/credits.js` — 역할마다 `names`에 이름을 적으면 빈 자리 대신 나온다.

## 시험

```bash
npm i -D playwright     # 한 번만
node tests/e2e.cjs      # 폴더를 직접 띄워서 시험 (E2E_SHOTS=폴더 로 화면 저장)
```

타이틀(메뉴 · Credits) → 난이도 → 프롤로그 · 이름 → 지도(축 연결) → 튜토리얼 전투(6×6 판 · 배경 · 양피지 카드) → 칸 화면 9종(배경 · 「떠난다」 버튼) → 사건(대사 장면 · 결과 · 새로고침 · 장면 도중 새로고침 · 건너뛰기 · 기시감) → 정예(승리 대사 · 보상 화면에서 새로고침) → 직접 저장 → 패배 · 재귀 → 발각 → 보스(보스 줄 + 6×6 · 사건 깃발 대사) → 챕터 끝까지 확인합니다 (45개).
