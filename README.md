# I — XII

열두 개의 시(時)를 되찾는 이야기 — 스팀(PC) 1920×1080 기준의 이야기 중심 로그라이크 덱빌딩 게임.

열두 시 전부의 권한을 가졌던 기계의 신 **크로노스**(이름은 바꿀 수 있다)는 난방 배분권을 둘러싼 다툼 끝에 자신의 작업실에서 **장력 가속 못총**에 죽었다.
서른두 해 뒤, 그는 회수소 지하에서 처음으로 **재귀**를 겪고 깨어난다. II부터 XII까지의 권능은 인간의 명령에 묶인 **신성체**가 되었고, 그를 믿는 신도들은 난방과 배급에서 밀려나 있다.
그는 그들의 도움 없이 먹고, 움직이고, 도시를 나갈 수 없다.

설계에서 정한 것과 임시로 둔 기본값은 [docs/DESIGN.md](docs/DESIGN.md)에 모두 적혀 있습니다.

## 실행

ES 모듈을 쓰기 때문에 `index.html`을 더블클릭(`file://`)으로 열면 동작하지 않습니다. 폴더를 간단한 웹 서버로 띄워 주세요.

```bash
python3 -m http.server 8000     # → http://localhost:8000
# 또는 npx serve · VS Code Live Server
```

설치 · 빌드는 필요 없습니다. 화면은 1920×1080 무대를 창 크기에 맞춰 비율 그대로 확대 · 축소하고, 남는 곳은 검은 여백으로 둡니다
(1280×1024 · 1366×768 · 1920×1080 · 2560×1440 · 3440×1440에서 확인).

## 저장

- **이어 하기** — 늘 자동으로 저장된다. 끈 자리로 돌아온다: 전투 중이면 그 전투를 처음부터, 승리 대사 · 보상 · 챕터 끝 화면이면 그 화면으로(보상은 두 번 받지 않음), 쓰러진 뒤면 재귀로. 칸에서 이미 고른 일(심연 · 천막 · 유물 제단 · 골목 · 사건 · 휴식)은 결과만 다시 보여 주고 두 번 받지 않는다.
- **사건 · 이야기 칸** — 장면이 끝난 뒤에 한 번 저장된다. 장면 도중에 끄면 이어 할 때 그 장면을 처음부터 (효과 · 회복이 두 번 들어가지 않음), 끝난 뒤면 결과 화면으로. 이야기 칸의 전투는 앞 대사를 이미 봤으면 곧장 전투로.
- **재귀 지점** — 챕터 시작 · 이야기 칸의 전투 직전 · 보스 앞에서 자동(횟수를 쓰지 않음), 그 밖에는 지도 오른쪽 위 「저장」으로 직접(챕터마다 횟수 제한, 난이도마다 다름). 09의 경로 선택 · 14의 휴식 판정은 재도전해도 그대로(경계가 두 번 오르거나 다시 굴리지 않음). 되돌아와도 인물들은 기억하지 않는다(기시감 대사 없음).
- 브라우저 `localStorage`의 `i12.run.auto.v1` · `i12.run.recur.v1` · `i12.settings.v1`에 들어 있다(**저장 판 3**). `i12.profile.v1`은 예전 판에서 겪은 사건 기록 — 새 판의 지도에는 덜 본 사건부터 나온다.
- 저장 판 1 · 2(1장이 전면 개작되기 전)의 여정은 이어 할 수 없다 — Start를 누르면 알려 주고, 새 게임을 시작하면 지운다.

## 내용 고치기

- **대사**: `src/data/story/prologue.js`(01 회상 · 02 각성), `src/data/story/ch1.js`(03~15 이야기 칸 · 16 · 17 보스 · 18 끝 장면 — 칸마다 `kind`: battle · talk · shop · rest, `safeRest`는 들어오면 먼저 회복).
  한 줄은 `{ who, face, text }` (`who`: hero · nar · marte · or · eda · barnett · doll · visitor · announce · broadcast · unknown · 적 이름). 연출은 `{ bg, cg, dial, paper, panel, sys, wait, fx, tint, amb, hero, exit, card }` (문법은 `src/scenes/scene.js` 맨 위).
  `{name}`은 플레이어 이름, `{name|을}` · `{name|이}` · `{name|은}` · `{name|과}` · `{name|으로}` · `{name|이라고}` · `{name|아}` 등은 받침에 맞는 조사. 이름은 04에서 정하므로 01~03의 지문은 「그」로 쓴다.
- **사람**: `ch1.js`의 `CH1_CAST` — `art`(전용 그림 슬롯) · `alt`(없을 때 대신 쓰는 그림) · `tone`(대신 쓰는 그림에 입히는 색조) · `voice`(타자 소리).
- **사건**: `src/data/events.js` — 사건 하나 = 제목 · 장소 · 때(`phase`: a · b · c · d) · 등장인물(`cast`) · 장면(`scene`). 선택지는 `desc`(얻고 잃는 것) · `cond`(조건) · `lack`(모자랄 때 이유), 효과는 `act(G => …)`, 결과 한 줄은 `after`. `G.flag('이름')`으로 세운 깃발은 다른 사건에서 `{ if: G => G.has('이름'), then: [...] }`으로 받는다.
- **지도 · 숫자**: `chapters.js`(21층 · 두 줄(`turn`) — `fixed`의 `'story:s03'`이 이야기 칸, `phases` · `moods`가 사이 층의 때와 칸 종류, 나머지는 사이 칸 비율 · 적 구성 · 부품 보상 · 기습 칸 수), `cards.js`, `relics.js`, `foes.js`, `items.js`, `difficulty.js`.
- **새 장**: `chapters.js`에 `CHAPTERS[2]`, `story/ch2.js`, `src/game/flow.js`의 `STORIES`에 한 줄. 새 보스는 `foes.js`의 `BOSSES`.
- **제작진(Credits)**: `src/data/credits.js` — 역할마다 `names`에 이름을 적으면 빈 자리 대신 나온다.

npm i -D playwright     # 한 번만
