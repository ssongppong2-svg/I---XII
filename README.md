# I — XII

하드 로그라이크 덱빌딩 턴제 스토리 카드게임.

## 전투 테스트판 (`index.html`)

5×5 격자 전투 프로토타입입니다. 설치·빌드 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.
(`assets/` 폴더와 같은 위치에 두어야 이미지가 적용됩니다.)

**스팀(PC) 게임 기준**으로 1920×1080 가로 화면에 맞춰 그리고, 마우스·키보드로 조작합니다.
다른 해상도에서는 화면 전체를 비율 그대로 확대·축소하고, 남는 곳은 검은 여백으로 둡니다.
1280×720 · 1366×768 · 1920×1200 · 2560×1440 · 3440×1440에서 잘림이나 스크롤이 없는지 확인했습니다.

### 화면 구성

| 위치 | 내용 |
|---|---|
| 위 | 로고 · 지금 전투(모드 · 루프 · 남은 코스트) / 낮밤 시계 / 규칙 · 설정 · 소리 버튼 |
| 왼쪽 | 주인공 얼굴(상황에 따라 표정이 바뀜) · HP · 과부하, 카드 · 적 설명 칸, 조작 안내 |
| 가운데 | 5×5 판, 그 아래 이번 루프 코스트 칸(기습 · 턴 공격 표시, 그 행동 뒤에 움직일 적 점)과 한 줄 조언 |
| 오른쪽 | 적(보스) 체력 · 과부하, 예고(턴 공격 / 적 행동 · 기습 칸 수), 적 목록(체력 · 순번 · 다음 행동), 전투 기록 |
| 아래 | 손패(최대 6장, 넘치면 겹침) · 뽑기 버튼 |

- **시작 화면**: 로고 · 전투 고르기 · 규칙과 조작 · 테스트 설정 · 핵심 규칙 6가지, 오른쪽에 주인공 그림
- **대사 장면**: 주인공은 왼쪽, 상대(상점 주인 · 적 · 암시장 상인)는 오른쪽, 감시망 방송 화면은 두 사람 사이 위쪽, 아래에 넓은 대사창

흐름: 시작 화면에서 **일반 전투** 또는 **보스전** 선택 → 전투 전 장면 → 전투(중간에 짧은 장면) → **승리 · 패배 엔딩** → 결과.
결과 화면에서 같은 전투를 다시 하거나 다른 전투로 바로 넘어갈 수 있습니다.

| 전투 | 판 | 적 | 이기는 조건 |
|---|---|---|---|
| 일반 전투 | 5×5 전부 | 감시탑 순찰대 3명 (시계 사수 · 방패 기사 · 폭탄병) | 적 전멸 |
| 보스전 | 맨 윗줄은 보스, 아래 4×5 | 중간 보스 **대형 감시기계** + 졸개 2명 (사수 · 폭탄병) | 보스 HP 0 (졸개가 남아도 승리) |

### 규칙

| 규칙 | 내용 |
|---|---|
| 코스트 | 이동 · 카드 · 추가 뽑기 모두 1코스트. 한 루프 4코스트, 턴 종료 버튼 없음 |
| 일반 적 | **2코스트마다 이동 또는 공격 1회.** 적마다 순번이 엇갈려 어떤 적은 1·3번째 행동 뒤, 어떤 적은 2·4번째 행동 뒤에 움직인다. 다음 행동은 판에 미리 표시되고(분홍 조준 표식 = 공격할 칸, 화살표 = 갈 칸) 실행 때 바뀌지 않는다 — 그 칸 밖에서 행동을 끝내면 피한다. 머리 위 숫자 1 = 내 다음 행동 뒤 |
| 카드 방향 | 카드를 쓸 때 **상하좌우 중 방향을 고른다.** 그 방향 범위에 적(보스전은 보스 줄도)이 있어야 쓸 수 있고, 범위 안의 적은 모두 맞는다 |
| 기습 폭격 | 루프의 **2번째 행동이 끝나는 순간** 빨간 줄이 폭발. 일반 전투에서도 터진다. 일반 적은 맞지 않는다 |
| 턴 공격 (보스전) | **마지막 행동이 끝나는 순간** 보스가 1회 공격. 패턴은 루프 시작 때 예고되고, 기습이 터질 때 범위(주황)가 드러난다 |
| 과부하 | 100이 되면 50으로 줄고 4코스트 동안 마비 — 행동해도 코스트만 빠진다(적은 그대로 움직임). 보스를 과부하시키면 4코스트 동안 기습·턴 공격 정지 |
| 낮밤 | 나+보스(일반 전투는 기습) 누적 30코스트마다 전환. 오전(낮): 기습 10칸, 줄이 판 끝까지 / 오후(밤): 기습 7칸 + 핏빛 타일(공격 카드 피해 ×3, 과부하 +40) |

### 조작

- 이동: `W` `A` `S` `D` · 방향키 · 옆 칸 클릭
- 카드: 마우스를 올리면 판에 범위가, 왼쪽 설명 칸에 효과가 나온다. 클릭하면 바로 사용(적이 여러 방향에 닿으면 먼저 선택). 키보드는 `1`–`6`으로 선택 → 한 번 더 누르거나 `Space`
- 조준: 카드를 고르면 조준한 방향은 청록 실선, 적이 닿는 다른 방향은 점선. 점선 칸에 마우스를 올리면 그쪽으로 조준, 조준한 범위를 클릭하면 사용. 키보드는 카드 선택 중 `W` `A` `S` `D`로 조준(이동하려면 `Esc`로 선택 취소)
- 적 정보: 판 위의 적이나 오른쪽 적 목록에 마우스를 올리면 왼쪽 설명 칸에 체력 · 다음 행동 · 방패 정면 여부가 나오고, 클릭하면 고정
- 뽑기 `Q` · 취소 `Esc` · 규칙 `H` · 소리 `M` · 시작 화면에서 `1` 일반 전투 · `2` 보스전

### 이미지

- **격자(전투)**: 주인공과 적 모두 SD로 표시. 주인공 SD는 공격 · 마비 · 피격 · 승패를 움직임으로 보여준다
- **전투 왼쪽 얼굴 칸**: 주인공 표정 그림에서 얼굴만 잘라 보여준다 — 평소 기본, 카드를 쓰면 조준, 맞으면 괴로움(HP가 1 남으면 부상), 마비되면 과부하, 이기면 씩 웃음
- **보스 줄**: 중간 보스 대형 감시기계 — 감시 눈이 든 윗부분을 가로 띠로 잘라 맨 윗줄을 채움 (탐조등도 그 눈에서 나옴)
- **대사 장면**: 주인공 표정 9종(기본 · 조준 · 과부하 · 씩 웃음 · 놀람 · 의문 · 괴로움 · 부상 · 분노), 상점 주인(합법 상점 주인 설정표의 전신 그림), 암시장 상인, 적 3종 스탠딩, 감시망 방송 화면의 대형 감시기계 전신, 신도들의 속삭임이 말할 때 흐릿하게 떠오르는 미지의 신도
- **규칙(?) 화면**: 적 도감 — 스탠딩 일러스트 + SD, 중간 보스 전신
- 양피지 카드 배경

체크무늬가 구워진 그림은 배경을 걷어내고, SD는 발끝이 칸 바닥에 닿게 잘라 넣었습니다. 표정 추가 · 규격은 [assets/README.md](assets/README.md) 참고.

### 테스트 설정 (⚙ 버튼 · 시작 화면의 테스트 설정)

루프 코스트, 기습 칸 수, 낮밤 전환 코스트, 턴 공격 판정 시점, 핏빛 배율, 일반 전투 적 수 · 보스전 졸개 수, 일반 전투 기습 켜기/끄기 등을 게임 안에서 바로 바꿔 볼 수 있습니다.
낮밤 즉시 전환 · 과부하 +50 · 적 하나 처치 · 보스 HP −50 · 일반 전투/보스전으로 재시작 · 무적 모드 같은 테스트 버튼도 있고, 설정은 브라우저에 저장됩니다.

### 테스트용으로 임시로 정한 값

확정되면 `index.html` 스크립트의 `DEFAULTS` · `CARDS` · `PATTERNS` · `FOES`만 바꾸면 됩니다.

- 중간 보스 대형 감시기계(인류 정부군, HP 150), 턴 공격 7패턴(못총 등 공격 이름은 임시), 카드 9종 15장
- 일반 적 이름 · 수치는 위 표 (시계 사수 · 방패 기사 · 폭탄병), 일반 전투 3명 · 보스전 졸개 2명
- 일반 적 행동은 낮밤 누적 코스트에 넣지 않음 (설정 "적 행동 1회 = 코스트"로 바꿔 볼 수 있음)
- 일반 적은 기습 폭격에 맞지 않고, 적의 공격끼리는 서로 맞지 않음 (폭탄병 자폭만 예외)
- 보스전 1행에서 옆으로 쓴 부채꼴도 보스 줄(0행)에 닿으면 보스가 맞음
- 전투 시작 직후 첫 행동 전에 바로 맞는 공격은 없게 (첫 순번 적은 한 번 쉬거나 다가옴)
- 턴 공격은 기습과 같이 "행동이 끝난 뒤" 판정 (설정에서 "지불 순간"으로 바꿔 볼 수 있음)
- 보스 기습 1회 · 턴 공격 1회를 각각 1코스트로 누적 (낮밤 전환 계산)
- 기습 피해 1, 턴 공격 피해 1~2, 장력 가속 못총 피격 시 과부하 +30
- 루프 시작 때 손패 3장까지 보충(최대 6장), 핏빛 타일은 밤마다 루프당 4칸 재배치
