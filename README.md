# I — XII

하드 로그라이크 덱빌딩 턴제 스토리 카드게임.

## 전투 테스트판 (`index.html`)

5×5 보드 보스전 프로토타입입니다. 설치·빌드 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.
(`assets/` 폴더와 같은 위치에 두어야 이미지가 적용됩니다.)

흐름: 시작 화면 → **프롤로그**(챕터 I — 감시탑 아래에서) → 전투(중간에 짧은 장면) → **승리 · 패배 엔딩** → 결과.

### 규칙

| 규칙 | 내용 |
|---|---|
| 전장 | 5×5. 맨 윗줄 5칸은 보스, 아래 4×5칸에서 주인공이 움직인다 |
| 코스트 | 이동 · 카드 · 추가 뽑기 모두 1코스트. 한 루프 4코스트, 턴 종료 버튼 없음 |
| 기습 폭격 | 루프의 **2번째 행동이 끝나는 순간** 빨간 줄이 폭발. 2번째 행동을 마친 위치가 빨간 줄 밖이어야 한다 |
| 턴 공격 | **마지막 행동이 끝나는 순간** 보스가 1회 공격. 패턴은 루프 시작 때 예고되고, 기습이 터질 때 범위(주황)가 드러난다 |
| 과부하 | 100이 되면 50으로 줄고 4코스트 동안 마비 — 행동해도 코스트만 빠진다. 보스를 과부하시키면 4코스트 동안 기습·턴 공격 정지 |
| 낮밤 | 나+보스 누적 30코스트마다 전환. 오전(낮): 기습 10칸, 줄이 판 끝까지 / 오후(밤): 기습 7칸 + 핏빛 타일(공격 카드 피해 ×3, 과부하 +40) |
| 카드 사거리 | 사거리 모양이 보스 줄에 닿아야 사용 가능 (예: 앞 3칸 부채꼴 = 보스 바로 앞줄에서만) |

### 조작

- 이동: `W` `A` `S` `D` · 방향키 · 옆 칸 터치
- 카드: `1`–`6`으로 선택 → 한 번 더 누르거나 `Space`로 사용. 마우스는 클릭하면 바로, 터치는 두 번 눌러 사용
- 뽑기 `Q` · 취소 `Esc` · 규칙 `H` · 소리 `M`

### 이야기 (테스트용 임시 문구)

| 장면 | 내용 |
|---|---|
| 프롤로그 (약 45줄, 선택지 2번) | 무너진 성당에서 깨어남 · 신도들의 속삭임 → 상점 주인(늑대 수인)이 세계와 싸우는 법을 알려주고 성물 카드를 외상으로 건넴 → 감시탑 탐조등과 「못박이」 등장 |
| 전투 중 (전투마다 한 번씩) | 첫 밤 · 보스 체력 절반 · 보스 첫 과부하 · 내 첫 과부하 |
| 승리 엔딩 | 「못박이」가 멈추며 "재가동 횟수… 열둘"을 남김 · 상점 주인이 외상값을 받으러 옴 · 챕터 II 예고 |
| 패배 엔딩 | 시곗바늘이 거꾸로 돌고, 제단 위에서 다시 깨어남 |

- 화자: 내레이션 · 기계 신(주인공) · 상점 주인 · 신도들의 속삭임 · 집행 병기 「못박이」
- 탭·클릭·`Space`로 넘김 (글자가 나오는 중이면 한 번에 다 보여줌), 선택지는 `1`·`2`로도 고를 수 있음
- **로그**(`L`) · **자동** · **건너뛰기** 버튼, 장소 자막 · 분위기 색(따뜻함·차가움·핏빛) · 번쩍임·흔들림 연출
- 대본은 `index.html`의 `PROLOGUE` · `INTERLUDES` · `EPILOGUE_WIN` · `EPILOGUE_LOSE`. 한 줄은 `{ who, face, text }`
- ⚙ 설정에서 전투 중 · 끝난 뒤 장면을 끄거나, **장면 미리보기**로 원하는 장면만 볼 수 있음
- 전투 중에는 보스가 짧은 말풍선으로도 반응 (`BARKS`)

### 이미지

주인공 표정 4종(기본 · 조준 · 과부하 · 씩 웃음)과 양피지 카드 배경이 `assets/`에 들어 있습니다.
보드 캐릭터도 상황에 따라 표정이 바뀝니다: 공격 카드 → 조준, 과부하 마비 → 과부하, 피격 → 부상, 승리 → 씩 웃음.
표정 추가 · 규격은 [assets/README.md](assets/README.md) 참고.

### 테스트 설정 (⚙ 버튼)

루프 코스트, 기습 칸 수, 낮밤 전환 코스트, 턴 공격 판정 시점, 핏빛 배율 등을 게임 안에서 바로 바꿔 볼 수 있습니다.
낮밤 즉시 전환 · 과부하 +50 · 보스 HP −50 · 무적 모드 같은 테스트 버튼도 있고, 설정은 브라우저에 저장됩니다.

### 테스트용으로 임시로 정한 값

확정되면 `index.html` 스크립트의 `DEFAULTS` · `CARDS` · `PATTERNS`만 바꾸면 됩니다.

- 보스 「못박이」(인류 정부군, HP 150), 턴 공격 7패턴, 카드 9종 15장
- 턴 공격은 기습과 같이 "행동이 끝난 뒤" 판정 (설정에서 "지불 순간"으로 바꿔 볼 수 있음)
- 보스 기습 1회 · 턴 공격 1회를 각각 1코스트로 누적 (낮밤 전환 계산)
- 기습 피해 1, 턴 공격 피해 1~2, 장력 가속 못총 피격 시 과부하 +30
- 루프 시작 때 손패 3장까지 보충(최대 6장), 핏빛 타일은 밤마다 루프당 4칸 재배치
