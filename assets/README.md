# assets — 이미지 슬롯

이 폴더에 아래 이름으로 이미지를 넣으면 게임이 자동으로 불러옵니다.
확장자는 webp · png · jpg를 인식하고, 파일이 없으면 기본 그림이 나옵니다.

## 격자 위 SD (전투)

전투에서는 격자 칸 위에 SD로 표시됩니다. 배경 투명, **캐릭터 둘레로 잘라 발끝이 그림 아래에 닿게** 해 두면 칸 바닥에 서 있는 것처럼 보입니다 (높이 480px 정도면 충분).

| 파일 | 캐릭터 | 원래 바라보는 쪽 | 상태 |
|---|---|---|---|
| `hero-sd.webp` | 주인공 | 정면 | 있음 |
| `enemy-rifle-sd.webp` | 시계 사수 | 오른쪽 | 있음 (체크무늬 걷어냄) |
| `enemy-shield-sd.webp` | 방패 기사 | 왼쪽 | 있음 |
| `enemy-bomb-sd.webp` | 폭탄병 | 왼쪽 | 있음 (체크무늬 걷어냄) |

적 SD는 주인공 쪽을 보도록 좌우가 자동으로 뒤집힙니다 (원래 바라보는 쪽은 `index.html`의 `FOES`에 `native`로 적혀 있음).
SD가 없으면 간단한 실루엣이 나오고, 주인공 SD가 없으면 예전처럼 스탠딩 그림을 격자에 올립니다.

## 일반 적 스탠딩 일러스트 (대사 장면 · 도감)

| 파일 | 적 | 상태 |
|---|---|---|
| `enemy-rifle.webp` | 시계 사수 | 있음 |
| `enemy-shield.webp` | 방패 기사 | 있음 |
| `enemy-bomb.webp` | 폭탄병 | 있음 (세로 2:3 캔버스에 맞추느라 위쪽 여백이 있음) |

세로 2:3(800×1200) 캔버스, 배경 투명, 아래 정렬. 대사 장면 오른쪽(상점 주인 자리)과 규칙(?) 화면의 적 도감에 나옵니다.

## 주인공 표정 (대사 장면)

모든 표정은 **같은 크기의 캔버스(세로 2:3, 예: 800×1200)에 같은 위치로** 그려져 있어야 표정을 바꿀 때 캐릭터가 흔들리지 않습니다.
배경은 투명해야 합니다. 체크무늬가 그림에 박힌 이미지는 그대로 쓰면 체크무늬가 보여서, 배경을 걷어낸 뒤 넣었습니다.
격자에서는 SD를 쓰기 때문에, 표정은 대사 장면에서만 바뀝니다 (SD가 없을 때만 격자에서도 표정이 바뀜).

| 파일 | 표정 | 쓰이는 대사 (예) | 상태 |
|---|---|---|---|
| `hero.webp` | 기본 | 표정을 따로 정하지 않은 대사 | 있음 |
| `hero-aim.webp` | 조준 | "좋아. 시간 맞춰 줄게." | 있음 |
| `hero-overload.webp` | 과부하 | "으… 몸이… 안 움직여…!" | 있음 |
| `hero-smug.webp` | 씩 웃음 | "공짜야?" | 있음 |
| `hero-surprised.webp` | 놀람 | 느낌표 대사 — "……!" · "잠깐, 두고 가는 거야?!" · "…자폭?!" | 있음 (입 옆 김 💨) |
| `hero-puzzled.webp` | 의문 | 물음표 대사 — "여기가… 어디지." · "…누구야?" · "…열둘?" · 톱니 문양 이야기 | 있음 (물음표) · 없으면 놀람으로 대신 |
| `hero-pain.webp` | 괴로움 | "…뜨거워. 이 피, 전부 나를 부르고 있어." · "…또, 여기야." | 있음 (아픔 표시) · 없으면 과부하로 대신 |
| `hero-wounded.webp` | 부상 | 패배 — "여기서… 끝이라고…?" | 있음 · 없으면 괴로움 → 과부하 순으로 대신 |
| `hero-angry.webp` | 분노 | "누구야, 넌." · "처분? 방금 깨어난 신한테…" | 있음 (💢) |

- 머리 옆 기호(💨 · 물음표 · 아픔 표시 · 💢)는 검은 선뿐이라 어두운 대사 배경에서 안 보여서, **기호에만** 옷의 흰 부분과 같은 종이색 테두리를 둘렀습니다.
- `hero-wounded.webp`는 몸이 기울어 발이 오른쪽으로 치우친 그림이라, 발끝을 기본 표정에 맞춰 옮겨 넣었습니다.
- 게임 안 **⚙ 설정 → 장면 미리보기 → 주인공 표정 모음**에서 9종을 차례로 넘겨 볼 수 있습니다 (파일이 없으면 무엇으로 대신하는지도 나옴).

## 대사 장면 인물

주인공과 같은 규격(세로 2:3, 배경 투명, 전신)이면 대사 장면에 크게 나옵니다.

| 파일 | 인물 | 쓰이는 곳 | 상태 |
|---|---|---|---|
| `shopkeeper.webp` | 상점 주인(합법) | 오른쪽 칸 — 프롤로그 · 순찰대 장면 · 엔딩 | 있음 (설정표에서 왼쪽 전신 그림만 오려냄) |
| `shopkeeper-hmph.webp` | 상점 주인 "흥." 표정 | 대사 | 없음 → 기본으로 대신 |
| `blackmarket.webp` | 암시장 상인 | 오른쪽 칸 — 일반 전투 승리 뒤 짧은 장면 | 있음 (검은 배경 걷어냄) |
| `believer.webp` | 미지의 신도 | 신도들의 속삭임이 말하는 동안 가운데 뒤편에 흐릿하게 | 있음 |

상점 주인과 암시장 상인 · 적은 오른쪽 칸을 번갈아 씁니다 (한 명이 말하면 다른 한 명은 빠짐).

## 중간 보스 — 대형 감시기계

| 파일 | 쓰이는 곳 | 규격 |
|---|---|---|
| `boss.webp` | 전투 판 맨 윗줄(보스 줄) | 배경 투명 · 가로 약 5:1 — 감시 눈이 든 윗부분을 잘라 만든 띠 (1040×199) |
| `boss-full.webp` | 대사 장면의 감시망 방송 화면 · 규칙(?) 화면 도감 | 배경 투명 · 전신 (1097×1200) |

보스 줄의 탐조등은 띠 그림 속 감시 눈 위치(가로 40%)에서 나옵니다. 그림을 바꾸면 `index.html`의 `.boss-row.has-art .searchlight` 위치도 맞춰 주세요.

## 올리는 법

GitHub 저장소 → `assets` 폴더 → **Add file → Upload files** → 파일 이름을 위 표대로 맞춰 올립니다.
게임 안 **?(규칙)** 화면 맨 아래 "이미지 슬롯"에서 적용됐는지 확인할 수 있습니다.
