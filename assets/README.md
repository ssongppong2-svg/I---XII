# assets — 이미지 슬롯

이 폴더에 아래 이름으로 이미지를 넣으면 게임이 자동으로 불러옵니다.
확장자는 webp · png · jpg를 인식하고, 파일이 없으면 기본 그림(실루엣 · 임시 그림)이 나옵니다.
게임 안 **규칙과 조작**(`H`) 맨 아래 「이미지 슬롯」에서 어떤 슬롯에 그림이 들어 있는지 바로 확인할 수 있습니다.

## 배경 그림

1920×1080(16:9) 기준. 비율이 다르면 가운데를 기준으로 꽉 차게 잘립니다. 파일이 없으면 지금의 어두운 바탕이 나옵니다.

| 파일 | 쓰이는 곳 | 상태 |
|---|---|---|
| `bg-title.webp` | 타이틀 | 있음 (받은 그림에서 Start · Settings · Credits · Exit 글자를 지우고, 메뉴는 게임이 그 자리에 다시 그림) |
| `bg-battle.webp` | 전투 화면 전체 (어둡게 눌러 깔림) | 있음 |
| `bg-rest-1.webp` · `bg-rest-2.webp` | 휴식 칸 — 칸마다 둘 중 하나 | 있음 (도시 야영지 · 숲 야영지) |
| `bg-shop.webp` | 상점 칸 (상점 주인 뒤) | 있음 |
| `bg-alley.webp` | 골목 칸 (숨기 · 좁은 골목 · 뒷골목 거래 · 지름길 모두) | 있음 |
| `bg-event.webp` | 사건(?) 칸 | 있음 |

## 격자 위 SD (전투)

전투에서는 격자 칸 위에 SD로 표시됩니다. 배경 투명, **캐릭터 둘레로 잘라 발끝이 그림 아래에 닿게** 해 두면 칸 바닥에 서 있는 것처럼 보입니다 (높이 480px 정도면 충분).

| 파일 | 캐릭터 | 원래 바라보는 쪽 | 상태 |
|---|---|---|---|
| `hero-sd.webp` | 주인공 | 정면 | 있음 — 새 픽셀 그림 |
| `enemy-rifle-sd.webp` | 시계 사수 (3장부터) | 오른쪽 | 있음 — 새 픽셀 그림 |
| `enemy-shield-sd.webp` | 방패 기사 (3장부터) | 왼쪽 | 있음 — 새 픽셀 그림 (방패병 SD 도트) |
| `enemy-bomb-sd.webp` | 폭탄병 (3장부터) | 왼쪽 | 있음 — 새 픽셀 그림 |

새 픽셀 SD는 둘레의 옅은 반투명 안개를 걷어내고, 캐릭터 둘레로 잘라 높이 480px로 맞췄습니다.

적 SD는 주인공 쪽을 보도록 좌우가 자동으로 뒤집힙니다. 원래 바라보는 쪽은 `src/data/foes.js`에 `native: 'L' | 'R'`로 적혀 있습니다 — 기계 적 그림이 오면 이 값만 맞춰 주세요.
