# assets — 이미지 슬롯

이 폴더에 아래 이름으로 이미지를 넣으면 게임이 자동으로 불러옵니다.
확장자는 webp · png · jpg를 인식하고, 파일이 없으면 기본 그림이 나옵니다.

## 주인공 표정

모든 표정은 **같은 크기의 캔버스(세로 2:3, 예: 800×1200)에 같은 위치로** 그려져 있어야 표정을 바꿀 때 캐릭터가 흔들리지 않습니다.
배경은 투명해야 합니다. 체크무늬가 그림에 박힌 이미지는 그대로 쓰면 체크무늬가 보여서, 배경을 걷어낸 뒤 넣었습니다.

| 파일 | 표정 | 쓰이는 곳 | 상태 |
|---|---|---|---|
| `hero.webp` | 기본 | 보드 캐릭터 기본 · 대사 기본 | 있음 |
| `hero-aim.webp` | 조준 | 공격 카드를 쓸 때 · 대사 | 있음 |
| `hero-overload.webp` | 과부하 | 과부하 마비 중 · 대사 | 있음 |
| `hero-smug.webp` | 씩 웃음 | 승리 · 대사 | 있음 |
| `hero-surprised.webp` | 놀람 | 대사 | 없음 → 기본 표정으로 대신 |
| `hero-wounded.webp` | 부상 | 맞았을 때 · 패배 | 없음 → 괴로움 → 과부하 순으로 대신 |
| `hero-pain.webp` | 괴로움 | 대사 | 없음 → 과부하로 대신 |
| `hero-angry.webp` | 분노 | 대사 | 없음 → 기본 표정으로 대신 |

## 그 밖

| 파일 | 쓰이는 곳 | 권장 규격 |
|---|---|---|
| `card-bg.webp` | 모든 카드의 배경 (지금은 양피지) | 세로 2:3 (예: 420×630) |
| `boss.webp` | 보스 (선택) | 배경 투명 · 가로 약 5:1 (예: 1040×200) · 맨 윗줄 5칸을 통째로 덮음 |

## 올리는 법

GitHub 저장소 → `assets` 폴더 → **Add file → Upload files** → 파일 이름을 위 표대로 맞춰 올립니다.
게임 안 **?(규칙)** 화면 맨 아래 "이미지 슬롯"에서 적용됐는지 확인할 수 있습니다.
