# assets — 이미지 슬롯

이 폴더에 아래 이름으로 이미지를 넣으면 게임이 자동으로 불러옵니다.
확장자는 png · webp · jpg · jpeg · gif 모두 인식하고, 파일이 없으면 기본 그림이 나옵니다.

| 파일 이름 | 쓰이는 곳 | 권장 규격 |
|---|---|---|
| `hero.png` | 주인공 SD 캐릭터 (보드 위) | 배경 투명 PNG · 세로형 약 3:4 (예: 480×640) · 발끝이 그림 아래쪽에 닿게 |
| `card-bg.png` | 모든 카드의 배경 | 세로형 약 3:4 (예: 300×410) · 글자가 위에 올라가므로 가운데가 너무 밝지 않게 |
| `boss.png` | 보스 (선택) | 배경 투명 PNG · 가로형 약 5:1 (예: 1040×200) · 맨 윗줄 5칸을 통째로 덮음 |

## GitHub 웹에서 올리는 법

저장소 → `assets` 폴더 → **Add file → Upload files** → 파일 이름을 위 표대로 맞춰 올리면 끝.
게임 안 **?(규칙)** 화면 맨 아래 "이미지 슬롯"에서 적용됐는지 확인할 수 있습니다.
